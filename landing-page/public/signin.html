Widget Sign-In

This page carries no API key. Visitors sign in to Ozwell for themselves

How it works

  1. Open the chat. The bubble is in the corner. Because this page configures no key, the widget opens on a sign-in screen rather than a chat box.
  2. Sign in. Use Google, request a code by email, or paste an Ozwell key you already have. The screen offers whichever methods this server supports.
  3. Chat, and use the page. The assistant can read and update the profile fields on the right. Every call shows up in the event log below them.
  4. Sign out from the control above the chat, then reload. The sign-in screen comes back.

The page never holds a key. Signing in mints a session that stands in for your own Ozwell key, so what you can do here is exactly what your account allows, and the usage is yours rather than the page owner's.

Try asking

  1. “What is my name?” — reads the fields on this page.
  2. “Change my name to Bob and my zip to 90210.” — writes them back.
